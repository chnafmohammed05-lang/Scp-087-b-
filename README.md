# SCP-087-B Game 🎮

A horror game prototype inspired by **SCP-087-B**, a creepypasta about descending an endless staircase into darkness.

## About the Game

SCP-087-B is a horror game where you descend deeper and deeper into an infinite staircase. Experience atmospheric tension and dread as you explore the mysterious depths below.

### Gameplay Features
- **Atmospheric Horror**: Immersive exploration of an endless staircase
- **Increasing Dread**: Tension builds as you descend deeper
- **Mysterious Encounters**: Discover what lurks in the darkness
- **Exploration-Based**: Uncover secrets hidden in the depths

## How to Play

Simply run the executable file to start the game:

```
SCP-087-B.GD.x86_64
for windows:
SCP-087-B.GD.rar
```
